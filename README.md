## 📖 Sobre o projeto

Este é um simulador de combate para jogos de RPG de mesa. O objetivo é permitir que dois personagens se enfrentem em turnos, com cálculo de dano, defesa, dados aleatórios e sistema de vida. Foi desenvolvido como parte dos meus estudos de lógica de programação e manipulação do DOM com JavaScript puro.

## 🧰 Tecnologias utilizadas

- **HTML5** – estrutura da página
- **CSS3** – estilização e responsividade básica
- **JavaScript (ES6+)** – lógica de combate, eventos e atualização dinâmica

## 🕹️ Funcionalidades

- Escolha de personagens (Guerreiro, Mago, Arqueiro)
- Rolagem de dados (d6, d8, d10)
- Sistema de turnos com ataques e defesas
- Exibição de logs do combate
- Reinício da partida
